# Coatform Painting — Website

Website for **Coatform Painting**: Toronto & GTA painters.
📞 416-786-1621 · ✉️ info@coatformpainting.ca

It's a fast static site (no framework) generated by `build.mjs` into `site/`, plus one serverless function for the AI estimator.

## What's included

- **Home page**: Gen-Z design with a dark/copper/cream palette, marquees, bento grid, colour swatches and a live map
- **18 service pages** (`/services/...`), each with its own SEO copy, pricing guide, FAQs and Service + FAQ schema
- **16 city pages** (`/service-areas/...`), each with unique local content, neighbourhoods, a live map and LocalBusiness/Service schema
- **Live interactive map** (Leaflet + OpenStreetMap/CARTO; no API key needed)
- **Free AI estimate** (`/free-quote/`): a 4-step form that asks whether the customer is supplying the paint, returns a rough price range labelled clearly as **ROUGH, not final**, with a call-to-action to 416-786-1621. The lead and the estimate it showed are emailed to you.
- **Appointment booking form** (`/book/`) and **contact form** (`/contact/`), plus a quick-quote form on most pages
- **Legal pages**: Terms & Conditions, Privacy Policy (PIPEDA/CASL), Warranty, Refund & Cancellation, Accessibility (AODA)
- **SEO**: unique titles and meta descriptions, canonical URLs, Open Graph/Twitter cards, JSON-LD (`HousePainter`, `Service`, `FAQPage`, `BreadcrumbList`, `BlogPosting`), `sitemap.xml`, `robots.txt`, `llms.txt`, an HTML sitemap, a blog with 3 articles, and dense internal linking (every service links to every city and vice versa)

## Deploy (Netlify, recommended)

1. Push this repo to GitHub, then in Netlify choose **Add new site → Import from Git** and pick this repo. `netlify.toml` already sets the build command and publish folder.
2. **Turn on the AI estimator:** go to Site settings → Environment variables and add `ANTHROPIC_API_KEY` (get one at console.anthropic.com). Without the key the estimator still works, but it uses the built-in pricing formula instead.
3. Point the domain `coatformpainting.ca` at Netlify (Domain settings).
4. **Activate form emails:** submit any form on the live site once. FormSubmit sends a one-time **activation email to info@coatformpainting.ca**. Click the link, and from then on every lead lands in that inbox.

## Edit content

| What | File |
|---|---|
| Phone, email, hours, social links, Google Analytics / Search Console IDs | `src/data/site.mjs` |
| Services (text, prices, FAQs) | `src/data/services.mjs` |
| Cities / service areas | `src/data/cities.mjs` |
| Estimator pricing rates | `src/assets/js/pricing.js` (`RATES`) |
| Blog posts | `src/data/posts.mjs` |
| Legal policies | `src/pages/legal.mjs` |
| Styles | `src/assets/css/style.css` |

To build locally: `npm install && npm run build`, then open `site/` with any static server (`npm run serve`).

> ⚠️ Review the policy numbers (warranty years, deposit %, cancellation windows) and have a lawyer look over the legal pages before launch. They are a strong starting template, not legal advice.
